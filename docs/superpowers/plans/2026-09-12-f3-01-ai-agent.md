# F3-01 兼容式模型适配与结构化领域工具实施计划

## 目标

完成 AI 工作台的第一个后端纵向切片：保存兼容式模型配置、创建 AI 会话、通过受控结构化工具读取项目资产或生成不落库的草稿 Patch，并以 SSE 返回模型事件。模型只能看到工具合同和脱敏上下文，不能获得数据库、文件系统、JMeter、Runner 或任意脚本工具。

## 范围与边界

- 只实现 OpenAI-compatible Chat Completions 的文本/工具调用适配和测试替身，不实现 AI 首页 UI、Curl/OpenAPI 导入、字段级差异确认和自动运行。
- 模型配置只保存地址、模型名和密钥引用；API Key 明文不进入请求 DTO、数据库、日志或 SSE。
- 工具首批固定为 `list_projects`、`list_api_cases`、`list_scenarios`、`get_run_report`、`create_draft_patch`；Patch 只返回结构化建议，不写资产表。
- AI 工具调用只通过 Platform Service/Repository 读取受控字段；工具注册表中不得出现数据库、JMeter、Runner、文件系统、Shell、脚本或任意 HTTP 工具。
- SSE 断开只停止当前输出，不改变资产；上游模型异常返回脱敏错误事件，普通手工 API 不受影响。

## 执行步骤

- [x] **先写合同测试**：模型配置禁止明文 key，工具白名单固定，Patch 不落库，模型响应/SSE 不含密钥；兼容式客户端和 Fake 客户端分别验证文本与工具调用事件。
- [x] **实现持久化与领域服务**：新增 V11 模型配置表、AI 会话/消息表，提供 DTO、Repository、Service 和校验；会话消息只保存脱敏文本和事件摘要。
- [x] **实现模型适配与工具注册表**：加入 OpenAI-compatible HTTP 客户端、FakeChatModelClient、工具 Schema/Dispatcher 和最小脱敏器；上游只接收占位符与结构化上下文。
- [x] **实现 REST/SSE**：提供模型配置列表/保存、会话创建/查询、消息 SSE 接口；端点继承当前登录和 CSRF 规则，SSE 不暴露上游凭据。
- [x] **验证与记录**：定向 Maven 合同测试、真实 PostgreSQL 迁移幂等测试和 2026-09-12 根目录全量门禁均通过；F3-02 以后能力不属于本计划范围。

## 交付验收

- 假模型完成一次工具调用合同测试，工具只能命中白名单结构化服务。
- 兼容式客户端正确处理文本响应、工具调用响应和上游非 2xx/超时。
- 模型配置和会话接口不返回 API Key；日志/SSE/持久化均不含密钥明文。
- `create_draft_patch` 只能产生待审阅 Patch，数据库资产行数和 revision 保持不变。
