# F2-07 Redis 受控步骤首个切片

## 目标

在现有场景编排中加入 Redis 数据源和四种白名单命令：GET、SET、DEL、EXISTS。数据源密码只引用平台密钥；SET/DEL 必须经过显式二次确认；不接受 Lua 或任意命令文本。

## 本轮范围

1. Flyway V8、Redis 数据源 CRUD/归档/恢复/连接测试。
2. 场景 REDIS 步骤校验与运行计划生成。
3. Runner 受控 Jedis 执行、变量解析、提取、基础断言和 JTL 摘要。
4. 自研 `RedisSampler` 的安全 JMX 产物，密码使用 JMeter 属性占位符。
5. Web 环境数据源表单与场景步骤编辑入口。

## 明确不做

- Lua、任意 Redis 命令、脚本执行。
- 条件、循环、嵌套场景和完整 Redis 报告交互。
- 将密码写入 JMX、日志、报告或浏览器响应。

## 验收

- Redis 7 Testcontainers 真实执行四种命令，未确认写操作不执行。
- JMX 结构只出现 `RedisSampler` 与白名单命令，不出现 Lua/JSR223/BeanShell/OSProcess。
- WSL Maven、Web Vitest/typecheck/build 和 Compose 配置门禁通过。
