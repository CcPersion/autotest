本目录把 `D:/AI/1AAAA重要文件/接口自动化/pytest-auto-api` 作为只读证据源，选取真实 README、源码中的能力示例，手工转换为平台原生资产描述。夹具不复制旧项目代码、YAML、证书、附件或业务数据，也不把旧 YAML 当作平台运行输入。

## 安全验收状态

当前五类安全门禁已有平台或 Runner 测试证据：密钥脱敏、危险 SQL、文件路径、提示注入、脚本组件。项目级 HTTP/HTTPS 目标白名单首片已经落地：项目 API/页面可配置，运行计划会固化规范化规则，Runner 会对带策略标记的计划再次校验，未列出的目标会在执行前拒绝；真实 PostgreSQL 回归已证明项目后续修改白名单不会改变旧运行计划。

SSRF/重定向的逐跳最终目标校验已收敛为 `COVERED`。Runner 使用平台审核的 `GuardedHttpSampler`，关闭 JMeter 底层自动重定向，并在每一跳调用 `HTTPHC4Impl` 前重新校验目标。真实本地 HTTP 测试覆盖允许→拒绝、允许→允许→拒绝和全允许链，未授权目标请求数为 0；缺失策略在首个请求前返回 `TARGET_NOT_ALLOWED`。修复后的 Runner 镜像 CLI 已能加载自定义 SaveService 与目标策略运行时类，JTL 有实际失败样本且不包含完整 query。
