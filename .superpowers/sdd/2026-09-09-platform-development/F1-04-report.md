# F1-04 实施报告：环境、类型变量与密钥

## 1. 结论与范围

- 状态：**完成，Sol 复审 PASS / APPROVE**。
- 已实现项目内环境 CRUD、归档/恢复、类型化 JSON 变量、`${secret:name}` 引用，以及只写不回显的密钥创建、替换和归档。
- 仅新增 V2 `secrets` 表；未实现代理、证书、JDBC、Redis、文件、Runner 注入、变量运行时解析或 F1-05 接口资产。

## 2. 后端实现

- 新增 `environment`、`secret` 领域的 Controller、Service、JdbcTemplate Repository、记录与响应 DTO。
- 环境变量必须为 JSON object，数字、布尔、null、对象和数组原样保存；Base URL 仅允许无 userInfo/fragment 的绝对 HTTP(S) URL。
- 密钥名严格使用 `[A-Za-z0-9][A-Za-z0-9._-]*`；`${secret:name}` 使用同一规则且必须命中当前项目活动密钥，引用文本只保存、不展开。
- 环境和密钥写操作限定项目与资源 ID，使用 revision 乐观锁；项目归档拒绝写入，跨项目资源统一 404。
- 密钥使用 Java 标准库 AES-256-GCM 加密，随机 12 字节 nonce，AAD 绑定项目和密钥 ID；主密钥只读 Base64 `AUTOTEST_MASTER_KEY`，缺失或非法时启动失败。
- API 仅返回固定八位掩码，不提供解密读取接口，也不返回 `value/ciphertext/nonce`。

## 3. 前端与真实流程

- 环境配置页接入真实当前项目，支持活动/归档环境、新建/编辑、JSON 变量、密钥引用选择、密钥创建/替换/归档及分类错误提示。
- 环境创建、更新、归档和恢复成功后通知平台壳层刷新顶部活动环境选择器；失败不触发刷新。
- 环境与密钥保存有请求进行中保护；密钥表单关闭或提交后清空明文输入。
- 新增真实浏览器用例和 F1-04 包装脚本；通用 E2E 脚本为 API 子进程注入测试主密钥，并在清理前扫描数据库及 API/Web 日志中的随机密钥哨兵。
- 数据库扫描检查密文字节和环境 JSON 均不含哨兵；浏览器拦截全部密钥响应，验证无明文、密文、nonce，且掩码固定。
