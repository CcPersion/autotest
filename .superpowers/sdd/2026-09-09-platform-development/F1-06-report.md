# F1-06 实施报告：Postman 式接口编辑页面

## 1. 状态与边界

- 状态：**实现完成，主控前端与真实浏览器验证通过，Sol 复审待补**。
- 本阶段把接口管理和接口用例页面从原型数据接入 F1-05 Platform API。
- 只支持已冻结的 GET/POST、Path/Query/Header、NONE/JSON Body、变量和基础断言结构；不实现浏览器直连目标服务、发送、JMeter、Runner、场景编排或运行报告。

## 2. 页面与客户端实现

- 新增接口定义客户端：列表、详情、创建、更新、归档，携带 `moduleId`、`includeArchived` 和 `revision`。
- 新增接口用例客户端：列表、详情、创建、更新、归档，携带所属定义和 `revision`。
- `ApiStudioView` 接入真实模块树、接口定义列表和接口用例列表；支持项目切换后的代次隔离、搜索、刷新和当前资产选择。
- 接口定义编辑器提供方法、URL、Path、Query、Header、Body 标签页；POST 自动进入 JSON Body，GET 自动切回 NONE。
- 接口用例编辑器提供请求覆盖、用例变量和断言 JSON 编辑，并以当前 revision 保存；版本冲突统一显示“版本已变化，请刷新后重试”。
- 页面明确显示“浏览器不直连目标服务”，响应区域仅作为后续 Runner 接入预留。
- 平台数据页不再显示“本地原型数据”标识；其他尚未接入页面仍保留原型标识。
